# Руководство пользователя — CryptoSafe Manager

CryptoSafe Manager — локальный менеджер паролей. Данные хранятся только на вашем компьютере в зашифрованной базе SQLite. Для доступа нужен **мастер-пароль**.

---

## 1. Установка и запуск

### 1.1 Требования

- Python 3.8 или новее
- Windows, Linux или macOS с графической средой (рабочий стол)
- ~200 МБ места для виртуального окружения и зависимостей

### 1.2 Установка из исходников

**Windows (PowerShell):**

```powershell
git clone https://github.com/lonelywarsaw/cryptosafe-manager.git
cd cryptosafe-manager
.\scripts\setup_windows.ps1
.\scripts\run_windows.ps1
```

**Linux:**

```bash
git clone https://github.com/lonelywarsaw/cryptosafe-manager.git
cd cryptosafe-manager
chmod +x scripts/setup_linux.sh scripts/run_linux.sh
bash scripts/setup_linux.sh
bash scripts/run_linux.sh
```

**macOS:**

```bash
git clone https://github.com/lonelywarsaw/cryptosafe-manager.git
cd cryptosafe-manager
chmod +x scripts/setup_macos.sh scripts/run_macos.sh
bash scripts/setup_macos.sh
bash scripts/run_macos.sh
```

Альтернатива без скриптов:

```bash
python -m venv .venv
# активируйте venv
pip install -r requirements.txt
python run.py
```

### 1.3 Запуск без установки Python (собранное приложение)

Соберите на **той же ОС**, где будете пользоваться:

| ОС | Команда | Запуск |
|----|---------|--------|
| Windows | `.\scripts\build_windows.ps1` | `dist\CryptoSafeManager\CryptoSafeManager.exe` |
| Linux | `bash scripts/build_linux.sh` | `dist/CryptoSafeManager/CryptoSafeManager` |
| macOS | `bash scripts/build_macos.sh` | `dist/CryptoSafeManager/CryptoSafeManager` |

Скопируйте **всю папку** `dist/CryptoSafeManager/` на целевой ПК.

### 1.4 Где хранятся данные

| Файл | Содержимое |
|------|------------|
| `config.db` (рядом с проектом или в каталоге приложения) | Путь к vault, настройки UI, профиль безопасности |
| `vault.db` (путь вы выбираете в мастере) | Зашифрованные записи, журнал аудита, ключи |

Не удаляйте `vault.db` без резервной копии — это единственная копия ваших паролей.

## 2. Мастер-пароль и хранилище

### 2.1 Первый запуск (мастер настройки)

1. Запустите приложение — откроется **мастер первого запуска**.
2. Задайте **мастер-пароль** (минимум 12 символов: строчные, заглавные, цифра, спецсимвол).
3. Подтвердите пароль во втором поле.
4. Нажмите **Обзор** и укажите путь к файлу хранилища (`vault.db`). Рекомендуется диск с резервным копированием.
5. В блоке **Настройки шифрования** выберите:
   - **По умолчанию** — PBKDF2, 100 000 итераций (быстрее вход);
   - **Высокая стойкость** — 600 000 итераций (медленнее вход, выше защита ключа AES).
6. Нажмите **OK**. Создаются `vault.db`, хеш пароля (Argon2) и соль в `key_store`.

### 2.2 Каждый следующий запуск

1. Откроется окно **Разблокировка**.
2. Введите мастер-пароль.
3. После нескольких неверных попыток включается задержка (1 с → 5 с → 30 с).
4. При успехе открывается главное окно; ключ шифрования держится в памяти до блокировки или выхода.

### 2.3 Смена мастер-пароля

**Правка → Сменить мастер-пароль** (доступно в разблокированной сессии).  
Все записи перешифровываются новым ключом; операция может занять время на больших хранилищах.

## 3. Записи: добавление, редактирование, удаление

### 3.1 Главное окно

- Таблица: название, маскированный логин, домен URL, дата изменения, колонка пароля.
- **Поиск** над таблицей — подстрока по полям; фильтры: `title:`, `username:`, `url:`, `notes:` (пример: `title:github`).
- **Показать пароли** на панели или `Ctrl+Shift+P` — временно показать пароли в таблице.

### 3.2 Горячие клавиши и навигация (UX-1)

Полный список в приложении: **Справка → Горячие клавиши**.

| Комбинация | Действие |
|------------|----------|
| `Ctrl+N` | Добавить запись |
| `Ctrl+E`, `F2`, `Enter` | Изменить выбранную запись (`Enter`/`F2` — при фокусе в таблице) |
| `Delete` | Удалить запись (фокус в таблице) |
| `Ctrl+F` | Перейти к полю поиска |
| `Esc` | Очистить поиск (в поле поиска) |
| `Ctrl+Shift+U` | Копировать логин |
| `Ctrl+Shift+C` | Копировать пароль |
| `Ctrl+Shift+A` | Копировать все поля |
| `Ctrl+Shift+B` | Очистить буфер обмена |
| `Ctrl+Shift+P` | Показать/скрыть пароли в таблице |
| `Ctrl+Shift+O` | Разблокировать хранилище |
| `Ctrl+Shift+L` | Заблокировать хранилище |
| `Ctrl+Shift+J` | Журнал аудита |
| `Ctrl+,` | Настройки |
| `Ctrl+Shift+Esc` | Режим паники |

**Навигация:** `Tab` переключает фокус между поиском и таблицей; **стрелки** перемещают выделение по строкам и колонкам; **двойной щелчок** по строке открывает редактирование. Элементы поиска и таблицы подписаны для программ чтения с экрана (accessibility).

### 3.3 Добавить запись

1. **Правка → Добавить** или контекстное меню.
2. Заполните: название, логин, пароль, URL, заметки, категорию/тег.
3. **Сгенерировать пароль** — длина и набор символов в диалоге.
4. **OK** — запись шифруется и сохраняется в `vault.db`.

### 3.4 Редактировать

1. Выделите строку → **Правка → Изменить** или двойной щелчок / контекстное меню.
2. Измените поля → **OK**.

### 3.5 Удалить

1. Выделите запись → **Правка → Удалить** или контекстное меню.
2. Подтвердите удаление. Операция необратима без резервной копии.

### 3.6 Копирование в буфер

Контекстное меню или **Правка**:

- **Копировать логин**
- **Копировать пароль**
- **Копировать всё** (все поля текстом)

## 4. Защищённый буфер обмена

### 4.1 Как это работает

1. При копировании секрет попадает в буфер ОС.
2. Запускается **таймер** (по умолчанию 30 с, настраивается в **Настройках → Безопасность**).
3. По истечении времени буфер **очищается** автоматически.
4. Если другая программа подменила буфер — приложение тоже может сбросить секрет.
5. При **блокировке**, **выходе** или **режиме паники** буфер очищается принудительно.

### 4.2 Индикация

- В статус-баре: оставшееся время до очистки.
- За 5 секунд до очистки — предупреждение.
- **Правка → Очистить буфер** — ручная очистка.

### 4.3 Настройки буфера

**Вид → Настройки → Безопасность:**

- Таймаут буфера (сек)
- Уровень безопасности (basic / advanced / paranoid) — в профилях
- Whitelist приложений (расширенный режим)

## 5. Импорт и экспорт данных

### 5.1 Экспорт хранилища

**Файл → Экспорт хранилища**

| Формат | Назначение |
|--------|------------|
| Encrypted JSON | Резервная копия с отдельным паролем экспорта |
| CSV | Совместимость с таблицами (без шифрования файла) |
| Bitwarden / LastPass | Миграция из других менеджеров |

Для зашифрованных форматов нужны **мастер-пароль** и **пароль экспорта**.

### 5.2 Импорт

**Файл → Импорт хранилища**

- Режимы: **объединить** (merge), **заменить** (replace), **пробный прогон** (dry-run).
- Лимит размера файла: 10 МБ; таймаут операции: 30 с.
- Перед replace рекомендуется **резервная копия**.

### 5.3 Обмен записями и QR

- **Файл → Поделиться записью** — зашифрованный пакет для другого пользователя (пароль или RSA-ключ).
- **Файл → QR просмотрщик** — просмотр/создание QR с зашифрованным payload (Windows: полный функционал; Linux: без сканера камеры по умолчанию).

### 5.4 Резервная копия (архив)

**Файл → Резервная копия** — создаёт `.csafe.zip` (копия `vault.db` + manifest с SHA-256).  
**Файл → Восстановить из копии** — заменяет текущую БД; сессия блокируется, нужен повторный вход.

## 6. Дополнительные функции

### 6.1 Журнал аудита

**Вид → Журнал** — события входа, CRUD, буфер, импорт/экспорт.  
При старте выполняется проверка целостности цепочки подписей.

### 6.2 Профили безопасности

**Вид → Настройки** — профили **Стандартный / Усиленный / Параноидальный**: таймауты буфера, автоблокировка, блокировка при сворачивании.

### 6.3 Системный трей и паника

- При включённой опции **сворачивание в трей** — окно скрывается, иконка в трее.
- **Ctrl+Shift+Esc** — режим паники: блокировка, очистка буфера, скрытие окна (без лишних диалогов).
- **Ctrl+Shift+L** / **Ctrl+Shift+O** — заблокировать и разблокировать вручную.
- Трей: разблокировать, показать окно, очистить буфер, выход.
- См. также раздел [3.2](#32-горячие-клавиши-и-навигация-ux-1).

### 6.4 Смена языка и темы

**Вид → Настройки → Внешний вид** — тема (системная / тёмная / светлая), язык ru/en.

## 7. Частые проблемы

| Проблема | Решение |
|----------|---------|
| PyQt6 не стартует на Linux | Установите пакеты Qt из подсказки `setup_linux.sh` |
| Забыт мастер-пароль | Восстановление невозможно без резервной копии и знания пароля |
| Буфер не очищается | Проверьте таймаут в настройках; **Очистить буфер** вручную |
| Импорт не видит записи | Проверьте формат файла и пароль экспорта |
