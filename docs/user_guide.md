# Руководство пользователя — CryptoSafe Manager

## Установка

1. Python 3.8+ и виртуальное окружение.
2. `pip install -r requirements.txt`
3. Запуск: `python run.py` или `python -m src.main`

## Первый запуск

1. Мастер настройки: мастер-пароль (≥12 символов), путь к файлу БД, параметры шифрования.
2. Разблокировка: введите мастер-пароль при каждом запуске.

## Записи

- **Добавить / изменить / удалить** — меню «Правка» или контекстное меню таблицы.
- **Поиск** — строка над таблицей; префиксы `title:`, `username:`, `url:`, `notes:`.
- **Пароли** — показ по строке или глобально (`Ctrl+Shift+P`).

## Безопасный буфер обмена

- Копирование логина/пароля из таблицы; авто-очистка по таймауту (настройки → Безопасность).
- Статус в строке состояния: оставшееся время до очистки.

## Импорт и экспорт

- **Файл → Экспорт / Импорт хранилища** — Encrypted JSON, CSV, Bitwarden, LastPass.
- Для зашифрованных форматов нужны мастер-пароль и пароль экспорта.
- **Поделиться записью** и **QR просмотрщик** — локальный обмен без облака.

## Резервная копия (спринт 8)

- **Файл → Резервная копия** — архив `.csafe.zip` (БД + manifest с контрольной суммой).
- **Восстановить из копии** — перезапись текущей БД; после восстановления сессия блокируется.

## Безопасность (спринт 7)

- **Профили** (Настройки): Стандартный / Усиленный / Параноидальный.
- **Авто-блокировка** при неактивности; иконка в трее при сворачивании.
- **Режим паники**: `Ctrl+Shift+Esc` или меню трея — блокировка, очистка буфера, скрытие окна.

## Журнал аудита

- **Вид → Журнал** — события входа, CRUD, буфер, импорт/экспорт; проверка целостности.

## Linux

После клонирования репозитория:

```bash
bash scripts/setup_linux.sh
bash scripts/run_linux.sh
```

Нужны Python 3.8+ и графическая сессия (локальный стол или X11). Буфер обмена работает через Qt; win32-специфичные функции недоступны.

## Известные ограничения

- Нет облачной синхронизации и браузерного расширения.
- QR-скан из файла на Linux: опционально (`pyzbar` + системная libzbar).
- Сборка `.exe` — Windows; на Linux — `python run.py` или PyInstaller под Linux.
