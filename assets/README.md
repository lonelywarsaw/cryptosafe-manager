# Иконка приложения

Положите сюда файлы (один из вариантов или оба):

| Файл | Назначение |
|------|------------|
| `icon.ico` | Windows: `.exe` (PyInstaller), панель задач |
| `icon.png` | Запуск из исходников (PyQt), квадрат ~256×256 |

Рекомендация для `.ico`: размеры 16, 32, 48, 256 px в одном файле.

После добавления файлов пересоберите exe: `python scripts/build_executable.py`
